slab-bot 데이터 모델 — 계층 피라미드

봇이 답하는 데이터를 구현 성숙도로 3층 쌓기. 아래로 갈수록 넓은 기반(이미 가진 것), 위로 갈수록 좁은 확장(붙이면 좋은 것). 각 블록엔 수집 방법 + 주기를 표기했고, 지속 데이터는 전부 자동 파이프라인으로 설계했다.

기본 slab 추가 붙인 DB 미구현·제안 수집 주기 ↻ 지속·자동 ↻ 수동→자동목표 ① 1회성/미수집
미구현 · 붙으면 좋은 DB 제안 전방위 질문 대응용. 신규 수집이 아니라 아래층 원천을 추출·파생해 채운다.

↑ 설계 원칙 — 지속 갱신 데이터는 무조건 자동 파이프라인으로: ①원천 입력→API 자동 동기화(기본 slab), ②문서 자동 추출(등기·인물·관계·니즈), ③크론 스크레이프(외부 시그널), ④원천 갱신 시 자동 재계산(벤치마크 파생). 사람 손이 필요한 곳(명함·인터랙션 요약)도 수기 최소화 + 자동 추출 우선으로 좁힌다. 모든 값은 출처·신뢰도·권한 티어를 달고 답변 근거로 실린다.
